# Kiosk Satellite SDK

Compile-time SDK 1 interfaces come from the Apache-2.0 licensed
[Reolink Doorbell Intercom](https://github.com/patrick11994/ks-reolink-doorbell-intercom)
plugin, which obtained them from the
[Kiosk Satellite plugin template](https://github.com/jxlarrea/kiosk-satellite-plugins).
Stock Kiosk Satellite supplies these classes at runtime; no SDK classes are packaged
in the plugin DEX JAR.
